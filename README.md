# ai-agent-learning

Hands-on learning notes and experiments covering AI agent loops, tool calling, MCP, Agent Skills, context and memory, planning, evaluation, security, and agent harnesses.

This repository is the learning and research workspace for understanding agent design, analysing existing frameworks, and recording reproducible experiments. It provides the conceptual foundation for two separate implementation projects: **Concord Runtime** (`concord-runtime`), a model-agnostic agent runtime, and **ConcordLoop** (`concord-loop`), a project exploring autonomous collaboration, mutual supervision, and cost-aware improvement.

Concord Runtime is the agreed name for the project currently hosted in `MaYaoquan/mini-agent`. The GitHub repository rename is pending; its existing Python package (`mini_agent`) and CLI command (`mini-agent`) remain unchanged.

Learning notes and small examples belong here; the standalone runtime and multi-agent supervision system belong in their own repositories. Detailed plans will be documented after discussion and agreement.
