# ai-agent-learning

Hands-on learning notes and experiments covering AI agent loops, tool calling, MCP, Agent Skills, context and memory, planning, evaluation, security, and agent harnesses.

This repository is the learning and research workspace for understanding agent design, analysing existing frameworks, and recording reproducible experiments. It provides the conceptual foundation for two separate implementation projects: `mini-agent`, a model-agnostic agent runtime, and `concord-loop`, a project exploring autonomous collaboration, mutual supervision, and cost-aware improvement.

Learning notes and small examples belong here; the standalone runtime and multi-agent supervision system belong in their own repositories. Detailed plans will be documented after discussion and agreement.
